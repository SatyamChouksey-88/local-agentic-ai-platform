Local Agentic AI Platform

A design for supervised AI agents that support every software delivery team, running on infrastructure the company controls.

Design stage. Documentation only, no implementation code yet. Project Book v2.0 (3 October 2026) supersedes v1.0.

Read the PDF Download DOCX

Core ideas

  • Trust through evidence: work is accepted only when deterministic evidence proves it, never because a model says it is done.
  • Humans in charge: irreversible actions need human approval, merges are always by a person, and secrets and payments are always denied.
  • Every team: Development, QA, BA and Product, Scrum and PM, DevOps and SRE, Security, and Documentation join through Team Packs, which are configuration, not new code.
  • Data stays in bounds: confidential and restricted work stays on company-controlled infrastructure.
  • Phase gates: the plan advances only when each gate's exit criteria are met.
