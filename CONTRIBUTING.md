# Contributing

Thank you for helping improve the Local Agentic AI Platform documentation.

## Workflow

1. Clone the repository and create a branch from `develop`.
2. Make your changes (README, Project Book in `docs/`, etc.).
3. Push and open a **pull request into `develop`**.
4. Promote to **`main`** via PR when ready for a stable snapshot.

See [CONTRIBUTING.md](CONTRIBUTING.md) on GitHub for full git commands.

## GitHub Pages

Pushing to `main` deploys the static site from `docs/` (`.github/workflows/pages.yml`).
